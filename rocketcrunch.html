GMTK Game Jam Entry

RocketCrunch

The countdown has started and the rocket isn't ready. Work through the control panel, solve every system's puzzle, and get it off the pad before the clock hits zero.

Built in Godot 4.5 · GDScript · Web (HTML5)

View on itch.io

The game is about 60 MB and may take a moment to load. Best played on desktop with a mouse.

How to Play

SystemWhat to do
WiringDrag wires to connect each colored port to its match
SwitchesFlip each switch into the right position
CrankSpin the handle clockwise to keep the power meter from draining out
Bug PadSquash the bugs crawling across the panel
ManualFlip through the launch manual for each level's instructions

The terminal tracks each system's progress. Clear them all before the 60-second countdown ends to launch. Run out of time and the rocket explodes. There are five levels, and progress is saved between sessions.

Technical Highlights

  • Data-driven levels. Each level is a LevelData resource holding its puzzle configs and manual pages, so new levels are built in the editor without new code.
  • Decoupled puzzle reporting. Each puzzle reports its progress to the terminal through a single set_progress() call, and the terminal alone decides when the level is won.
  • Global systems as autoloads. GameState, MusicManager, SoundManager, and SceneTransition run as singletons that persist across scenes.
  • Persistent progress. Completed levels are saved as JSON to user://, which maps to browser storage on the web build, and unlock the next level.
  • Rotation input. The crank computes the wrapped angle change between frames and only accepts clockwise motion, so the player has to actually spin it.
