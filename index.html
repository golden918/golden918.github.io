  • Enhancement One: Software Design and Engineering. The CS 350 smart thermostat was refactored to separate its state machine from the Raspberry Pi hardware using an abstract interface, dependency injection, defensive error handling, and a 15-test suite that runs without hardware.
  • Enhancement Two: Algorithms and Data Structures. The CS 370 TreasureHuntGame Q-learning agent received a SumTree-based Prioritized Experience Replay memory with O(1) insertion and O(log n) sampling, verified by 12 unit tests.
  • Enhancement Three: Databases. The CS 465 Travlr Getaways MEAN stack application received a redesigned MongoDB schema, indexing, filtering and pagination, an aggregation pipeline, a data migration, hardened authentication, and 54 integration tests.

Each artifact page includes the original code, the enhanced code, and a narrative explaining what I changed and what I learned. The informal code review video walks through all three artifacts before enhancement. Together, they show a developer who can design clean systems, choose the right algorithms, manage data responsibly, and build security in from the start.
